# Password Generator

A small browser-based password generator built as a JavaScript practice project. It generates a random password based on selected character types and a target length.

## Features

- Choose password length (2–30)
- Include/exclude character sets:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Symbols
- Displays the generated password on the page
- Shows a prompt if no character set is selected

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript

## Setup & Run Instructions

1. Clone or download this repository.
2. Open `index.html` in a web browser.


## Notes

This is a personal learning / practice project. It’s intended to demonstrate basic DOM interaction and simple random string generation, not to be production-ready.
